Entry for the [gta6-clipper-01 bounty on make.fun](https://make.fun/bounty/gta6-clipper-01).

A vertical clip cut from Rockstar's official Grand Theft Auto VI Trailer 1 — the police-chase moment — with a hook line and a make.fun pitch, published as a public YouTube Short: https://www.youtube.com/shorts/zAlEKVjRWs0

`main.ts` copies `VIDEO.json` (the Short's URL) to the output directory.

```sh
node main.ts
```
